## 1. 보드 2(제너 장착) — R13 스윕 실측 결과

캡처는 전부 **손을 고정해서 안정적으로 누른 상태**(움직이는 접촉은 노이즈로 판명 — `HW_MOTOR_TOUCH_REVIEW_20260911.md` 참고)로 수행. `g_TouchADCLog` 20개 원시 ADC 카운트 기준.

| R13 | 미터치 범위(count/V) | 마른손 범위(count/V) | 마른손 중 임계값(당시 3.0V=2457) 이하 연속개수 | 젖은손 범위(count/V) |
|---|---|---|---|---|
| 4.1M (8.2M×2∥) | 2496~2501 / 3.05V | 1489~2734 / 1.82~3.34V | 8개 (15개 필요 → **실패**) | 382~529 / 0.47~0.65V |
| 2.35M (8.2M∥3.3M) | 2592~2597 / 3.17V | 2374~2787 / 2.90~3.40V | 2개 (**실패**) | 778~969 / 0.95~1.18V |
| **8.2M (단독)** | 2458~2466 / 3.00~3.01V | 707~1379 / 0.86~1.68V | **20개 (전부 통과)** | 387~415 / 0.47~0.51V |

참고: 보드 1(제너 없음, R13=8.2M)은 미터치 3.73~3.78V, 마른손 1.85~2.96V로 매우 안정적 (`HW_MOTOR_TOUCH_REVIEW_20260911.md` §3 참조).

## 2. 핵심 발견 — R13과 "베이스라인 마진" vs "터치 분리폭"은 반비례 트레이드오프

| R13 | 베이스라인 – 임계값(3.0V) 마진 | 베이스라인 – 마른손 최댓값 분리폭 |
|---|---|---|
| 2.35M | +0.17V | 0.27V (약함) |
| 4.1M | +0.05V | 1.23V (양호) |
| 8.2M | **+0.003V (거의 0)** | **1.32V (최대)** |

- R13을 낮추면 베이스라인이 임계값에서 멀어져(좋아짐) 안정적이 되지만, 동시에 터치 시 전압 하강폭도 같이 줄어든다 — 분압회로가 GND쪽(제너 누설이든 터치저항이든) 변화에 덜 민감해지기 때문.
- R13을 높이면 반대로 베이스라인 마진은 줄지만 터치 분리폭은 커진다.
- **제너가 있는 한, R13 값만으로는 두 마리 토끼를 동시에 잡을 수 없다.**

이 발견 때문에 "R13을 낮춰서 제너 문제를 해결" 전략(§1의 4.1M, 2.35M 시도)은 모두 마른손 디바운스 실패로 끝났음.

## 3. 최종 채택안 — R13=8.2M(단독) + 소프트웨어 임계값 하향

R13=8.2M에서는 베이스라인(2458~2466)과 터치 신호(387~1379) 사이에 **약 1000카운트(≈1.2V)의 빈 구간**이 존재 — 임계값만 그 구간 중앙 쪽으로 옮기면 양쪽 마진을 동시에 확보 가능.

**적용 내용** ([main.c:1754-1764](../main.c#L1754-L1764)):
```c
// Touch threshold: 4095 : 5V  =  x : 2.3V  ->  x = 1884
if ( rTouchADC > (4095 * 2.3) / 5 )   // Not Connect (이전: 3.0V / 2457)
```

| 항목 | 새 임계값(1884, 2.3V) 대비 마진 |
|---|---|
| 미터치(2458~2466) | +574~582카운트 (+0.70~0.71V) |
| 마른손(707~1379) | −505~1177카운트 (−0.62~1.44V) |
| 젖은손(387~415) | −1469~1497카운트 |

**하드웨어 확정**: R13 = **8.2M 단독** (병렬저항 불필요, 원래 스펙 값과 동일).
**소프트웨어 확정**: 임계값 3.0V → **2.3V**로 하향.

→ 부품 교체(SOD-523 저누설 TVS 등) 없이, **기존 제너(DZ11, SOD-123) + 원래 R13(8.2M) 그대로 두고 임계값 재조정만으로 해결**될 가능성이 가장 높은 조합.

## 4. (참고) SOD-123 저누설 ESD 부품 조사 결과 — 현재는 보류

§3 결과가 좋아서 부품 교체는 일단 불필요해졌지만, 조사한 내용은 향후 참고용으로 남김:

- onsemi, Nexperia, Vishay **3사 모두 저누설 ESD 전용 TVS 라인은 SOD-523/SOD-923 이하 패키지에만 존재**, SOD-123에는 일반 제너/스위칭 다이오드 계열만 있음 (즉 SOD-123 풋프린트를 유지하면서 저누설 부품으로 교체하는 조합은 시장에 사실상 없음).
- 패키지 변경이 가능하다면 1순위 후보: **onsemi ESD5Z5.0T1G** (SOD-523, IR≈0.05µA 실측 확인).
- §3 방안이 현장 검증까지 통과하면 이 조사는 "플랜 B"로 보류.
